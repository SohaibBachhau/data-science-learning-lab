# Time-Series Intuition

This folder explains important time-series terms in plain language with almost no mathematics.

Use it when you want to answer questions such as:

> What is stationarity?

> What is causality?

> What is mean reversion?

without immediately giving formulas or technical definitions.

The goal is to be able to explain each idea naturally first, then use the formal notes when more precision is needed.

## How to use this folder

Try to explain a term from memory before opening its page. If your explanation captures the main idea, you understand the concept even if you do not remember every formula.

For derivations, assumptions and exam calculations, return to the permanent notes in the parent `time-series` folder.
