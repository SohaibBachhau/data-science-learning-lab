# Knowledge

This directory contains my permanent and continuously improving
knowledge base.

Information is organized by subject rather than by university course.
Each concept should have one primary location, even when it appears in
multiple courses or projects.

Course notes, assignments and exam preparation may link to these
permanent notes.

## How to use the knowledge base

Use three levels depending on how much detail you need:

```text
story overview
→ permanent concept notes
→ derivations, exercises and applications
```

A `story.md` file gives the low-friction narrative for a developed branch. It is meant for quick review and orientation, not as a replacement for the detailed notes.

Story files should be added only when a branch has enough real content to tell a useful connected story. Empty subject areas should not receive filler overviews.
